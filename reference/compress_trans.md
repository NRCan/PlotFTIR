# Compression Transformation

used in \`compress_low_energy()\` utilisé en \`compress_low_energy\`()\`

## Usage

``` r
compress_trans(intercept = 2000, ratio = 5)
```

## Arguments

- intercept:

  the wavenumber at which compression starts le nombre d'onde auquel la
  compression commence

- ratio:

  the rate of compression (larger numbers are more compressed) le taux
  de compression (des nombres plus grands sont plus compressés)
