# Get Fit Method

Determine the types of peaks used to create the \[fit_peaks()\] object.

Déterminez les types de pics utilisés pour créer l'objet
\[fit_peaks()\].

## Usage

``` r
.get_fit_method(fitted_peaks)
```

## Arguments

- fitted_peaks:

  An object from \[fit_peaks()\].

  Un objet de \[fit_peaks()\].

## Value

A character value for the peak type fitted to the spectra.

Une valeur de caractère pour le type de pic ajusté aux spectres.
