# Print PlotFTIR Data

Pretty print method for PlotFTIR data structures, showing spectral
range, inferred resolution, intensity type, number of samples, and
sample IDs.

Méthode d'impression jolie pour les structures de données PlotFTIR,
montrant la plage spectrale, la résolution inférée, le type d'intensité,
le nombre d'échantillons et les ID d'échantillons.

## Usage

``` r
# S3 method for class 'PlotFTIR_data'
print(x, ...)
```

## Arguments

- x:

  A PlotFTIR data object.

  Un objet de données PlotFTIR.

- ...:

  Additional arguments passed to print.

  Arguments supplémentaires passés à print.

## Value

Invisibly returns the object.

Renvoie l'objet de manière invisible.
